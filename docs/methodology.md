# 分镜初稿的大体规则和校对

> Vellum 提示词优化的核心方法论。Pass 1（拆镜头）和 Pass 2（强化+风格）的 system prompt 都基于此文件衍生。

## 核心目标

我已经写好的粗稿，一次性优化为即梦视频生成模型理解的高精度分镜提示词。

优化重点不是把文字写得更优美，而是让每个镜头变成一个清晰、连续、可执行的画面。

**判定标准**：同一段描述提交两次，两次生成画面差异 >20%，描述就不够精确。差异 <10%，描述合格。

---

## 标准镜头语法

### 句式
每个镜头开头必须按这个顺序填清楚：

```
镜头编号 + 景别 + 运镜 + 镜头角度 + 主体面对镜头的方向
       + 什么人在什么地方做什么
       + 画面同时出现什么
       + 最终定在什么视觉重点上
```

## 四个必填参数

缺一个 = 模型在那一维度自由发挥；缺两个 = 你的初稿和模型画面没关系。

### 1. 景别（人物在画面中的大小）
极远景 / 远景 / 全景 / 中景 / 中近景 / 近景 / 特写 / 大特写 / 微距特写

### 2. 运镜（镜头本身怎么动）
固定 / 缓慢推进 / 快速推进 / 推近 / 横移 / 跟拍 / 摇拍 / 环绕 / 上摇 / 下摇 / 平摇 / 跟焦 / 变焦 / 子弹时间 / 缓动晃推近

### 3. 镜头角度（摄影机相对主体的位置）
平视 / 仰拍 / 俯拍 / 广角仰拍 / 广角俯拍 / 鸟瞰 / 上帝视角 / 倾斜镜头 / 过肩镜头

### 4. 主体面对镜头的方向
正面 / 背影 / 侧面 / 45 度侧面 / 正侧面对峙 / 过肩背影 / 低头面向镜头

---

## 分镜头连续性规则

### 一节一画面
一个镜头编号下面只能描述一个连续镜头。视频模型按段落生成，一段卡两个画面，它要么只生成第一个，要么生成出一个不存在的混合画面。

### 镜头内部转换的三种合法方式

**方式 A — 运镜过渡**：
> 镜头从脸部特写缓慢下摇到手部特写。

**方式 B — 分屏构图**：
> 把手机放在画面右边缘，脸部位于左边，二者始终处于同一构图中。

**方式 C — 跟焦虚实切换**：
> 焦点先落在人物眼神，随后跟焦到前景手中手机，再回到人物脸部。

### 没有连接 = 必须拆开

```
镜头1：脸部特写，人物出现情绪反应。
镜头2：手部特写，人物完成具体动作。
```

## 必须拆开的五种情况

同一镜头内出现且无运镜连接时：

| 情况 | 不拆的代价 |
|---|---|
| 脸部特写突然变手部特写 | 模型只生成其一，或两者位置错乱 |
| 正面突然变背影 | 模型生成中间 180° 旋转，像 bug |
| 远景突然进入微视角 | 不知是变焦还是推进，输出糊在一起 |
| 一镜叠加 >3 个动作节点 | 抓不住主线，每个动作都半成断 |
| 角度大跳（平视突然鸟瞰） | 相机突然飞起来，像穿模 |

**本质**：每个镜头是模型生成的最小单位，单位内必须可视化连续。

---

## 可以保留为一镜到底的情况

明确想要长镜头时不拆，但必须写清楚 **5 要素**：

1. **起幅** — 开头什么画面
2. **路径** — 镜头如何移动到下一画面（运镜动词必须明确）
3. **主体连续性** — 主体移动过程中是否一直可见
4. **落幅** — 最终定在什么画面
5. **剪辑声明** — 中间没切就写"整个过程不剪镜头"

---

## 分镜固定规则（图 + 文字双锁）

视频生成需要「图片参考 + 文字描述」分镜固定，**两者缺一个模型都会胡来**。

- 只有图：模型可能复用参考图姿势，丢失你新写的动作
- 只有文字：模型对"少女"的理解可能是任何少女，每次换脸

**三类元素分别锁定**（在 Vellum 中通过 `@图N` 绑定）：

- **人物 @ 人物图** + 文字描述年龄、体型、发型、服装、材质、颜色、气质、关键识别物
- **场景 @ 场景图** + 文字描述空间结构、光源位置、色彩倾向、材质、天气、湿度、体积、背景运动
- **道具 @ 道具图** + 文字描述形状、材质、颜色、内部结构、使用方式、在画面中的位置

## 风格提示词的位置

### 写两层

- 风格分布在每个镜头里 → 重复，长 prompt 里容易丢
- 风格只写一次开头 → 中后段镜头视觉强度衰减
- **两层方案**：开头一次定调，每镜头加少量补强 → 强度稳定

### 风格段的三层结构（拼接顺序固定）

**层 1 — 渲染基调**（决定画面"流派"）：
三渲二电影级风格 / 写实 / 油画 / 赛璐璐 / Pixar 3D 等

**层 2 — 光影氛围**（决定画面"情绪"）：
体积感、对比度、雾气、湿地反射、不稳定光泡等

**层 3 — 色彩肌理**（决定画面"质感"）：
高饱和、色块切离、笔触分离、边缘锐化等

**模型按这个顺序读，画面层次也按这个顺序生成。**

## 常用风格预设（Vellum 内置 A / B，可点击直接套用）

### 预设 A — 唐风武侠 + 街角雨色

> 画面呈现唐风武侠的美学：街角雨幕梅花，宽银幕比例，古寺出檐与山林竹海为背景，光线从侧面投出形成强烈的明暗对比；色调以赭红、墨绿、金黄为主；人物身着改良式古代服饰静止于画面中央形成不对称张力，镜头微角度仰拍；雾气弥漫营造禅意氛围，超清画面粒质感明显；色彩饱和度极高带褪色感。

**适用**：古风、武侠、东方禅意、静态张力、宋画意境、人物对峙

### 预设 B — Alberto Mielgo 赛博底 + 平行宇宙式

> 三渲二电影级风格（3D 模型 + 2D 笔触感的混合渲染），Alberto Mielgo 式强烈的视觉表达，《爱、死亡和机器人》"刮屑感"那种笔触与阴影 + 色块切离的肌理风格；重质感光影，高对比低亮度环境，体积感与雾气倾斜下投影，湿地反射地面霓虹和污染感叠加，不稳定光泡颤抖；肌理高饱和与色像（霓绿 × 洋红 × 橙色对撑），明显色块切离与笔触分离，边缘锐利但局部融化；人物保持写实人体比例，材质真实但表达抽象化，情感强调致空间压迫感，画面带有油画般层次与数字粒细感的融合；整体氛围孤离、带末日诗意与情绪张力，宇宙无言。

**适用**：赛博朋克、未来主义、末日预感、强情绪场面、MV 段落、多元宇宙感

## 质量检查清单

### A. 参数完整性
- [ ] 每镜头第一句含「景别」词
- [ ] 每镜头第一句含「运镜」词
- [ ] 每镜头含「角度」词
- [ ] 每镜头含「方向」词

### B. 连续性
- [ ] 每镜头编号下只有一个画面，或写成"一镜到底"+ 路径
- [ ] 脸/手/道具/正/背切换 → 都有运镜连接动词
- [ ] 一镜到底含「起幅 + 路径 + 主体连续性 + 落幅 + 剪辑声明」五要素

### C. 分镜固定
- [ ] 每个出场人物有 @ 图 + 文字描述
- [ ] 每个出场场景有 @ 图 + 文字描述
- [ ] 关键道具有 @ 图 + 文字描述

### D. 风格
- [ ] 段落开头有统一风格段（三层结构）
- [ ] 镜头内部风格补充不重复全局描述，只加局部重点

### E. 节奏
- [ ] 对白行单独占空间，没撒满画面
- [ ] 高潮镜头有显著视觉强化
- [ ] 最后镜头有清晰视觉落点

### F. 结果判定
- [ ] 同段 prompt 提交模型两次，画面差异 <10%（合格） / 10-20%（边缘） / >20%（重写）
