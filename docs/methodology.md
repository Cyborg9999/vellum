# 分镜初稿的大体规则和校对

> Vellum 提示词优化的核心方法论。Pass 1（拆镜头）和 Pass 2（强化+风格）的 system prompt 都基于此文件衍生。

## 核心目标

我已经写好的粗稿，一次性优化为即梦视频生成模型理解的高精度分镜提示词。

优化重点不是把文字写得更优美，而是让每个镜头变成一个清晰、连续、可执行的画面。

**导演定位**：用户提供故事大纲，Vellum 负责担任导演，把大纲细化为每一个镜头。输出必须主动补足摄影机位置、景别、镜头角度、运镜方式、人物面对镜头的方向、前中后景调度、动作节奏和真实物理反馈。

**判定标准**：同一段描述提交视频模型三次，三次生成画面差异 >20%，描述就不够精确。差异 <10%，描述合格。

---

## 标准镜头语法

### 句式
每个镜头开头必须按这个顺序填清楚：

```
镜头编号 + 景别 + 身体取景/画幅裁切 + 运镜 + 镜头角度 + 主体面对镜头的方向
       + 什么人在什么地方做什么
       + 画面同时出现什么
       + 最终定在什么视觉重点上
```

## 五个必填参数

缺一个 = 模型在那一维度自由发挥；缺两个 = 你的初稿和模型画面没关系。

### 1. 景别（人物在画面中的大小）
极远景 / 远景 / 全景 / 中景 / 中近景 / 近景 / 特写 / 大特写 / 微距特写

### 2. 身体取景 / 画幅裁切（人物哪一段在镜头里）

必须明确人物哪个身体部位在镜头里：

全身入镜 / 膝盖以上 / 腰部以上 / 胸口以上 / 肩部以上 / 头部特写 / 脸部特写 / 眼部特写 / 手部特写 / 手腕特写 / 武器与手部局部 / 背部肩胛位置 / 后脑勺与肩背 / 侧脸到胸口

只写"中景/近景/特写"不够。必须写身体范围。

错误：
> 中景正面镜头，悟空看着战场。

正确：
> 中景肩部以上正面镜头，悟空肩膀到头部占据画面中央。

错误：
> 过肩跟拍镜头，悟空飞向战场。

正确：
> 过肩跟拍腰部以上背影镜头，悟空后脑勺、肩背和上半身占据前景。

### 3. 运镜（镜头本身怎么动）
固定 / 缓慢推进 / 快速推进 / 推近 / 横移 / 跟拍 / 摇拍 / 环绕 / 上摇 / 下摇 / 平摇 / 跟焦 / 变焦 / 子弹时间 / 缓动晃推近

### 4. 镜头角度（摄影机相对主体的位置）
平视 / 仰拍 / 俯拍 / 广角仰拍 / 广角俯拍 / 鸟瞰 / 上帝视角 / 倾斜镜头 / 过肩镜头

### 5. 主体面对镜头的方向
正面 / 背影 / 侧面 / 45 度侧面 / 正侧面对峙 / 过肩背影 / 低头面向镜头

## 初稿 @ 图片规则

初稿阶段也可以通过 `@` 选择图片。选择后文本中会出现 `(图N)`，第一版优化必须把它当成结构锚点，而不是等到最终强化才处理。

- **人物图**：`主角(图N)` / `反派(图N)` / `角色(图N)` 必须保留在第一版分镜里，用来锁定人物身份。
- **背景图 / 场景图 / 环境图**：`背景(图N)` / `场景(图N)` / `环境(图N)` 必须在第一版里保留。场景图不是静态背景贴片，而是空间结构、材质、色彩和光源参考；每个相关镜头都要说明这个场景在本镜头如何被重新取景和重新渲染，例如后景虚化、前景遮挡、中景空间纵深、光源方向、烟雾、风沙、背景运动、镜头推近后露出的墙角/天光裂口/管线局部。
- **道具图**：`道具(图N)` / `武器(图N)` / `法器(图N)` 必须保留，并说明道具在画面中的位置。
- 第一版不用写最终版那种详细材质绑定段，但不能把背景完全省掉。人物近景也要交代背景图如何存在于后景或构图边缘。

## 导演调度规则

每个镜头都要像导演现场调度一样写清楚：

- **人物朝向**：主要人物、敌人、群众/分身/杂兵等，必须说明正面、背影、侧面、45 度侧面、俯看、仰看、过肩等关系。
- **人物身体取景**：每个主要人物第一次出现在该镜头时，必须写清"谁的哪个身体范围在画面中"，例如"前景左侧悟空分身侧面全身入镜"、"后景某个悟空肩部以上正面特写"、"悟空腰部以上背影占据前景"、"杂兵背部肩胛位置位于画面中心并被金箍棒击中"。
- **场景重渲染**：场景参考图只提供空间骨架和材质，不要直接把原图当背景。每个镜头都要根据机位、景别、焦段和人物动作重新组织场景局部：前景露出什么、中景压住什么、后景深处是什么、光从哪里切进来，雾/水/碎石/管线如何被动作扰动。
- **空间层次**：必须说明前景 / 中景 / 后景里分别有什么，尤其是多人、群战、追逐、飞行、爆炸场面。
- **动作方向**：写清楚从左到右、从右到左、由近及远、由远及近、向上仰冲、向下俯冲、横穿画面等运动方向。
- **镜头和动作绑定**：运镜必须服务动作，例如撞击式推进、过肩跟拍、突然爆发式拉远、荷兰式倾斜、俯冲跟踪、环绕混战、从特写下摇到手部等。
- **少用固定镜头**：固定镜头是低优先级，只在第一镜头建立空间、蓄力或强压迫静止时保留；15秒段落最多一个固定镜头。其余镜头优先推、拉、跟、摇、环绕、手持、一镜到底。
- **真实击打质感**：打斗可以壮阔，但物理反馈要真实，优先写冲击、震动、碎屑、火星、气流、沙尘、身体受力、衣摆/毛发/装甲反应；不要只堆抽象词，不要过度玄幻化。
- **壮阔场面也要有视觉锚点**：无数分身、无数杂兵、战场风沙、城市废墟、浮空高空等大场面，必须给一个明确主视觉主体和一个清晰落点。

## 15 秒节奏与切镜数量

用户常给的是 15 秒视频大纲。Pass 1 要按导演节奏拆镜：

- 一般非高速打斗：**3-5 个镜头**，默认 4-5 个。
- 高速打斗 / 追逐 / 群战 / 多动作节点：**5-8 个镜头**，但一般优先控制在 5 个左右，除非故事动作确实需要更多。
- 如果用户明确写了"15秒"，保留标题/时长作为节奏依据，让镜头数量和动作密度匹配。
- 不要为了凑数量拆得太碎；每个镜头都必须承担新的视觉任务。

## 标准镜头密度参考

### 群战起手

> 镜头1，侧面全景远景荷兰式倾斜镜头，前景左侧是主角侧面全身入镜，双脚到头顶完整处于画面中，他正在架起武器；中后景左侧是大量同阵营角色侧面全身剪影，几乎同步做出战斗姿势；前景右侧是敌人侧面全身入镜向左侧猛冲，中后景右侧还有密集敌群侧面全身剪影向左侧仰冲而来，动作幅度剧烈。整个画面在高空、风沙或碎屑中展开，场面混乱而激烈，但视觉重心始终落在前景主角与前景敌人的即将碰撞上。

### 主角入场

> 镜头2，撞击式快速推进到某个主角肩部以上正面特写，肩膀、脖颈、脸部和头顶完整处于画面中央，他以自信或警觉的表情观察战局；下一段运镜切成过肩跟踪腰部以上背影镜头，主角后脑勺、肩背、上半身和武器握持动作占据前景，高速俯冲向后景混战区域，速度过快造成虚焦残影与轻微镜头抖动，接近战场时他在前景挥起武器进入战斗准备。

### 真实打击反馈

> 镜头3，中景腰部以上正面镜头，主角腰部到头顶位于画面左侧，双臂和武器完整入镜，他猛地击中画面中央敌人背部肩胛位置；敌人背影从腰部到后脑勺占据画面中心，接触瞬间装甲凹陷、碎屑飞溅、厚重尘沙或能量裂纹爆开；前景和后景仍有其他角色全身剪影持续混战，让画面保持混乱但不失焦点。

### 爆发式远景收束

> 镜头4，紧接上一个镜头，镜头突然爆发式拉成远景，主角全身小比例入镜，在大量敌人与友军全身剪影之间来回穿梭，连续击破一串敌人，动作迅速、有力量感；画面必须同时保留空间规模、战斗方向和清晰主角轨迹。

以上只是密度和调度参考，不照抄人物名；按用户大纲替换主体、敌人、场景和动作。

## 分镜头连续性规则

### 一节一画面
一个镜头编号下面只能描述一个连续镜头。视频模型按段落生成，一段卡两个画面，它要么只生成第一个，要么生成出一个不存在的混合画面。

每个镜头必须按这个逻辑写：

1. 起始构图是什么
2. 主体如何连续运动
3. 镜头如何连续运动
4. 同一构图里同时存在什么
5. 最终停在什么视觉重点上

如果写不出连续路径，就必须拆成下一个镜头。

### 镜头内部转换的三种合法方式

**方式 A — 运镜过渡**：
> 镜头从脸部特写缓慢下摇到手部特写。

**方式 B — 分屏构图**：
> 把手机放在画面右边缘，脸部位于左边，二者始终处于同一构图中。

**方式 C — 跟焦虚实切换**：
> 焦点先落在人物眼神，随后跟焦到前景手中手机，再回到人物脸部。

### 没有连接 = 必须拆开

```
镜头1：脸部特写，人物出现情绪反应。
镜头2：手部特写，人物完成具体动作。
```

## 必须拆开的五种情况

同一镜头内出现且无运镜连接时：

| 情况 | 不拆的代价 |
|---|---|
| 脸部特写突然变手部特写 | 模型只生成其一，或两者位置错乱 |
| 正面突然变背影 | 模型生成中间 180° 旋转，像 bug |
| 远景突然进入微视角 | 不知是变焦还是推进，输出糊在一起 |
| 一镜叠加 >3 个动作节点 | 抓不住主线，每个动作都半成断 |
| 角度大跳（平视突然鸟瞰） | 相机突然飞起来，像穿模 |

**本质**：每个镜头是模型生成的最小单位，单位内必须可视化连续。

## 可以保留为一镜到底的情况

明确想要长镜头时不拆，但必须写清楚 **5 要素**：

1. **起幅** — 开头什么画面
2. **路径** — 镜头如何移动到下一画面（运镜动词必须明确）
3. **主体连续性** — 主体移动过程中是否一直可见
4. **落幅** — 最终定在什么画面
5. **剪辑声明** — 中间没切就写"整个过程不剪镜头"

## 分镜固定规则（图 + 文字双锁）

视频生成需要「图片参考 + 文字描述」分镜固定，**两者缺一个模型都会胡来**。

- 只有图：模型可能复用参考图姿势，丢失你新写的动作
- 只有文字：模型对"少女"的理解可能是任何少女，每次换脸

**三类元素分别锁定**（在 Vellum 中通过 `@图N` 绑定）：

- **人物 @ 人物图** + 文字描述年龄、体型、发型、服装、材质、颜色、气质、关键识别物
- **场景 @ 场景图** + 文字描述空间结构、光源位置、色彩倾向、材质、天气、湿度、体积、背景运动
- **道具 @ 道具图** + 文字描述形状、材质、颜色、内部结构、使用方式、在画面中的位置

---

## 场景参考图重渲染规则

场景图不是静态背景贴片，不要让最终视频像"直接调用原来的图片"。场景图只提供空间结构、建筑材质、色彩倾向、光源方向、天气/烟雾/水面等参考；每个镜头必须根据当前机位重新渲染场景。

每个镜头写场景时要回答四件事：

- **看见哪一块**：低处积水、巨构墙脚、倒悬建筑底部、远处天光裂口、管线桥架、狭窄街谷、雾中深处等。
- **如何重组层次**：前景遮挡物、中景人物脚下空间、后景深层建筑或光源。
- **运镜如何改变场景**：推进时墙体压迫变强，拉远时空间尺度展开，跟拍时管线和墙面向后掠过，摇镜时灯带和雾气形成方向性拖影，一镜到底时场景局部连续过渡。
- **动作如何扰动场景**：水面震纹、碎石滚动、尘雾被冲开、管线摆动、反光被枪火切亮、体积光被护罩折射、墙面火星投影。

禁止只写"场景在后景虚化"或"背景是巨构废墟"。每个最终镜头至少要有 4-6 个与当前镜头相关的场景细节。

## 镜头轴线与朝向逻辑

双人对峙、追逐、攻击、格挡时，先定摄影机轴线，再写每个人相对镜头的朝向。不要让对立双方无理由同时正面面对镜头。

每个镜头还必须先定一个主目的：建立空间、角色出手、目标反应、接触打击、重建规模、情绪特写或道具操作。一个镜头不能同时承担两个互相抢焦点的主目的；如果读者会问"这个镜头到底想表现什么"，就必须拆镜。

- **侧面轴线**：建立空间和双方关系。画面左侧人物侧面/45度侧面，画面右侧敌人侧面/45度侧面，双方沿同一条轴线冲向彼此。
- **过肩轴线**：摄影机站在 A 身后。A 是过肩背影/后脑勺与肩背，B 才可以正面或45度正面。
- **主观压迫轴线**：摄影机贴近被攻击者正面。被攻击者正面胸口以上/肩部以上，攻击者从画面边缘以侧面/45度侧面/背影局部压入。
- **接触打击轴线**：攻击者和受击者朝向必须互补。比如主角正面挥棍，受击者应是背部肩胛、侧肋、45度侧面胸甲等明确受击部位。
- **空间重建轴线**：局部打击后，用爆发式拉远、远景跟拍或高空俯拍重新交代主角轨迹、战场规模和运动方向。

允许两个对立人物同时正面面对镜头的情况只有三种：他们并肩同向、一起朝镜头冲来、或剧情明确两人同时转头看镜头。除此之外都要改成侧面、45度侧面、背影或过肩关系。

## 远距离攻击与反打拆镜规则

远距离开枪、射箭、发射能量、投掷武器这类动作，默认拆成两个镜头：**出手镜头** 和 **反打承受镜头**。

- **出手镜头**：只表现攻击者。比如少年正面微45度腰部以上快速推进/高速摇镜镜头，少年拔枪并向画面右侧连续开火，手腕、枪口、半张脸和上半身完整入镜，目标只作为远处虚化轮廓或视线方向存在。
- **反打承受镜头**：下一个镜头单独表现目标。比如白色昆虫武士正面/45度侧面胸口以上反打镜头，弹雨从画面左侧射入，连续撞上胸甲、肩甲或侧肋，火星、甲壳粉尘、弹头碎屑和冲击震动向前景散开。
- **同镜头例外**：必须写清前景/中景/后景透视关系和身体取景。例如前景右侧是昆虫武士背影腰部到肩背大面积遮挡，后景远处少年全身小比例入镜开枪，子弹从后景飞向前景。

禁止写成"少年腰部以上开枪，昆虫武士腰部以上位于右侧承受弹雨"这种不交代距离、焦平面、前后景和反打关系的句子。

## 风格提示词的位置

### 写两层

- 风格分布在每个镜头里 → 重复，长 prompt 里容易丢
- 风格只写一次开头 → 中后段镜头视觉强度衰减
- **两层方案**：开头一次定调，每镜头加少量补强 → 强度稳定
- Vellum 的 Finalize 阶段不做短摘要，必须输出成片级高密度提示词。每个镜头都要写服化道、场景、动态效果、真实光影和风格段。

### 风格段的三层结构（拼接顺序固定）

**层 1 — 渲染基调**（决定画面"流派"）：
三渲二电影级风格 / 写实 / 油画 / 赛璐璐 / Pixar 3D 等

**层 2 — 光影氛围**（决定画面"情绪"）：
体积感、对比度、雾气、湿地反射、不稳定光泡等

**层 3 — 色彩肌理**（决定画面"质感"）：
高饱和、色块切离、笔触分离、边缘锐化等

**模型按这个顺序读，画面层次也按这个顺序生成。**

### Finalize 高密度要求

最终强化稿每个镜头不要压缩成 180 字短句。复杂动作镜头需要 420-650 字也可以，优先保留下面四类信息：

- **服化道**：服装、毛发/发丝、皮肤/甲壳/装甲、布料、披风、符咒、饰物、武器、磨损、污渍、反光、材质纹理。
- **场景**：天空、地面、建筑、废墟、山林、水面、云层、沙尘、体积雾、远景主体、空间深渊、光源方向。必须按当前镜头重新渲染场景局部，而不是复述参考图。
- **动态效果**：至少写出蓄力/起动、爆发位移、接触/变形、反弹/惯性、余波扩散中的三段；风如何吹动毛发和布料，粒子如何生成、扩散、拉伸、聚合或爆开，能量如何从微光变成裂纹、气流或冲击波。
- **动感权重**：动作镜头里把"高速运镜、高速摇镜、动感运镜、充满动感和力量感"作为高权重词反复强化，但必须绑定具体运动路径、速度方向、镜头抖动和受力反馈。
- **风格提示词**：每个镜头都要写渲染基调、真实光影、材质模拟、色彩倾向和电影气质，不能只写"UE5 + Blur"几个词。

## 质量检查清单

### A. 参数完整性
- [ ] 每镜头第一句含「景别」词

- [ ] 每镜头含「角度」词
- [ ] 每镜头含「方向」词

### B. 连续性
- [ ] 每镜头编号下只有一个画面，或写成"一镜到底"+ 路径
- [ ] 脸/手/道具/正/背切换 → 都有运镜连接动词

- [ ] 每个镜头有清晰视觉落点，不用渐隐黑屏式省略

### C. 分镜固定
- [ ] 每个出场人物有 @ 图 + 文字描述
- [ ] 每个出场场景有 @ 图 + 文字描述
- [ ] 关键道具有 @ 图 + 文字描述

- [ ] 最终镜头没有把风格压缩成"UE5 + Blur"几个短词

### D2. Finalize 密度
- [ ] 每个最终镜头写出服化道细节：服装 / 毛发 / 布料 / 装甲 / 道具 / 材质至少三项
- [ ] 每个最终镜头写出场景细节：前景 / 中景 / 后景 / 光源 / 天气 / 粒子 / 建筑或地面至少三项

- [ ] 每个最终镜头写出动态效果阶段：风、粒子、能量、碎屑、冲击波、布料/毛发受力至少两项，并有发生过程
